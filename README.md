# Readapt Lab — Chrome extension v0.3

Readapt Lab персонализирует оформление статей и проводит локальный A/B-эксперимент между исходным и персонализированным режимами.

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `extension`.
5. Закрепите Readapt Lab на панели Chrome и обновите уже открытые страницы.

После установки автоматически откроется стартовый экран с демонстрационной статьёй и проверкой готовности.

## Автономная демонстрация

Если открыть `popup.html` как обычный файл, включится автономный режим: вставьте текст статьи длиной от 500 знаков, начните чтение и нажмите «Закончить и пройти тест». Данные сохраняются в `localStorage`. При прямом открытии `quiz.html` без предварительно начатой сессии теста ещё нет — начинать нужно с `popup.html`.

## Возможности

- Шесть параметров типографики: шрифт, размер, высота строки, межбуквенный и межсловный интервалы, ширина колонки.
- Выбор фона с автоматическим светлым/тёмным цветом текста.
- Режим без отвлекающих элементов.
- Строка-подсказка, следующая за курсором.
- Локально сохранённый профиль.
- Рандомизированные сессии в обычном или персонализированном режиме.
- Три автоматически составленных cloze-вопроса по тексту статьи.
- Дашборд понимания, времени и усталости; экспорт JSON.
- Автоматическая калибровка по пониманию, времени и комфорту.
- Исследовательский режим с согласием, анонимным кодом и скрытым условием.
- Предустановленные профили, фокус на абзаце и озвучивание.
- Сравнительная аналитика и экспорт CSV.

## Ограничения первой версии

- Эвристическое извлечение текста лучше всего работает на обычных статьях с тегами `article`, `main` и `p`.
- Cloze-тест проверяет узнавание содержания, но не заменяет вручную составленные вопросы на глубокое понимание.
- На системных страницах Chrome, в Chrome Web Store и во встроенном PDF viewer content script не запускается.
- Автоматическое скрытие отвлекающих блоков может затронуть полезную навигацию на некоторых сайтах.

## Приватность

Профиль, извлечённый для активной тестовой сессии текст и результаты сохраняются в `chrome.storage.local`. Сетевых запросов нет.
